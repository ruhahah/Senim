# Senim — можно ли доверять ответу ИИ?

Вставьте ответ ChatGPT, Gemini или другого ИИ. Senim разобьёт его на утверждения,
сверит каждое с источниками (Википедия kk/ru/en, учебная база, реестр DOI) и подсветит:
🟢 подтверждено · 🟡 спорно · 🔴 опровергнуто · ⚪ мнение / нет данных — с объяснением и цитатой.

Кейс «AI Trust», WIT Teens Hackathon.
